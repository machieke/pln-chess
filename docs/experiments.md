# Reproducible experiments

`training.factory.generate(seed=1729)` produces controlled contrasts and seeded reference-game positions using exactly `chess==1.11.2`. It enumerates the production candidate grammar and labels it only in training. The committed fixture JSON records FENs, focus moves, family/game groups, splits, oracle version and content hash. `artifacts/dataset-manifest.json` records run counts and hashes.

Strict train, validation, heldout-transfer and adversarial splits are disjoint by structural family/game. Controlled-transfer intentionally pairs a training motif with a whole-position file translation and is reported separately. Pawn orientation and special-move fixtures remain separate named demonstrations. Synthetic fixtures are sparse controlled inputs, not a representative distribution of chess games. The factory rejects invalid starting positions using the training-side oracle. Tests verify the dataset hash and require the named double-check, mate and stalemate fixtures to have those actual properties.

Complete-set evaluation reports precision, recall, F1, exact legal-move-set accuracy, false-legal rates, self-check false positives, per-piece statistics, abstention and incomplete counts. Abstentions count as false negatives for recall. It scores the complete oracle move set, so missing candidates hurt exact-set accuracy. Boundary candidates are retained; metrics are also reported for in-board destinations to expose easy-negative inflation.

The calibration experiment fits empirical strength-decile label frequencies on validation. Empty bins use the validation base rate. Held-out Brier/log loss/ECE use this frozen mapping, never raw confidence as a probability. This small validation set cannot establish reliable calibration; probabilities are diagnostic only.

Ablations use one focus move per training fixture to bound runtime and report that narrower scope. Variants are full, geometry-only, weaker descriptor prior (piece plus signed offset), no post-move exposure context, no dependence handling, and no candidate occupancy context. Removing occupancy does not erase occupancy from every opponent frame; this is an explicitly limited ablation. The geometry-only model retains the common candidate grammar. Correlated copies use the same dependence group and changed source labels to exercise exclusion. Models/evidence for each variant are exported.

The absolute baseline exists only in `evaluation/`: it stores empirical labels indexed by piece, absolute source/destination and promotion. It deliberately cannot share weights across translation. Its poor transfer should not be interpreted as a comparison against a modern chess learner. One-example sample efficiency is demonstrated on the controlled rook motif; broad evidence-to-competence sample complexity is not established.

Benchmarks measure single-candidate and full-position batches for sparse rook, pinned rook and a multi-piece position, three repetitions each. JSON reports p50/p95/p99, native invocations, grounded atoms, pieces/candidates, process high-water RSS and checkpoint bytes. Each batch starts a cold native interpreter. Three repeats are a smoke benchmark, not a stable tail-latency estimate. Out-of-budget runs return incomplete.

Run `bash scripts/bootstrap.sh` for audit, fixture regeneration, training, proofs, complete-set scoring, ablations, calibration, benchmark, tests and reports. `scripts/deliver.py` recreates generated training evidence atomically through a temporary ledger; user-supplied ledgers are not modified. Exact commands and measured numerical outcomes are in the generated final report.
