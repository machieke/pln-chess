# State-local identities and observation evidence

Every raw state generation receives a reversible 64-cell identity map before ray selection. Piece and cell identifiers are opaque hashes in separate namespaces. Typed field positions determine which symbols name pieces, cells and list tails. Coordinates appear in the audited import mapping. Native schemas continue to bind state, relative offsets, roles, shape and path membership. Only the registered observed neighborhoods contribute sentences. [Observation constructor](../../research/cycle20/observations.py)

The constructor visits sorted distinct endpoint pairs, retaining the frozen constructor's fact order on first delivery. Each source event, observed state version, observation category and canonical statement identifies one evidence stamp. A shared occupied or empty cell therefore supplies the same stamped sentence to both rays. Replaying the same capture is idempotent. Two separately identified captures with equal statement text retain distinct records and shared ancestry remains visible. Counting distinct stamps does not establish statistical independence.

The crossing controls demonstrate two different meanings of the legacy local name cell_0 and a single new identity for the same shared coordinate. Empty, blocked and withheld crossings, reversed roles, an entity renamed cell_0, a different state, reordered rays, expanded scope and repeated observations were exercised. Unobserved board cells receive no occupancy claim merely by receiving an ID.
