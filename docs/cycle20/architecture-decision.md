# Architecture decision

Use one bounded native derivation per immutable observed workspace and model generation when several related readouts share the same ordered inputs. Support validated disk restoration and continuation. A single-owner native session can retain the active queues for subsequent requests. Retain the existing whole-generation invalidation and raw reconstruction policy when observations or learned parameters change. Admission and cache policy remain host responsibilities.

The next architectural decision is the workspace boundary. Additional rays share derivation work but also compete for bounded task and belief slots. Select workspace size using measured task pressure and required target coverage. Keep identical-input parity and explicit evidence generations as acceptance criteria for any future operational evaluation.

On the paired fixture, a fresh combined batch took a median 1.83 s. A fresh process restoring the serialized queues for selection took 4.23 s despite zero new derivations. An already-resident read took 1.21 ms for the registered late observation. These timings favor native batching for scheduled multi-target work, live reads for suitably bounded active sessions, and serialization for replay or process replacement.
