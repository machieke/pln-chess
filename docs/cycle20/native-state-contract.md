# Native state contract

A successful native return contains two ordered tuples. The first contains remaining tasks and the second contains retained beliefs. Each entry preserves the complete parsed S-expression, native variable spelling, decimal truth-value tokens and ordered stamps. JSON arrays retain tuple order. Restoration sends the complete pair in one native binding so shared variables across partial conditionals retain their scope. [State validator](../../research/cycle20/state.py) · [Partial native snapshot](../../artifacts/cycle20/witnesses/continuation-states/False-0.json)

The versioned envelope binds the state, evidence and model generations, runtime-manifest digest, policy and identity-map version. It records ordered initial fact, rule and task hashes, separate queue capacities, cumulative selected steps, completion, resource status, native receipt digest, transport mode and parent continuation reference. The snapshot identifier hashes the canonical envelope. A new execution can have a different receipt and snapshot while reproducing exactly the same scientific state.

Import requires an expected generation and an independently retained snapshot identifier. Identity and hash checks precede execution. The decoder accepts bounded chess constructors, declared arities, numeric TV components, namespaced stamps and bounded native queues. It rejects missing fields, unrecognized constructors, stale model/runtime identities and partial process results. A content hash alone provides no authority to declare an arbitrary replacement current. The host publishes only complete raw-input rebuilds with matching ordered input identities. Read-only restoration records the served source generation and the new readout receipt.

Fresh input is limited to 256 initial tasks and 256 initial beliefs. Native returned queues use their recorded positive capacities, up to 512. A real native step expanded 256 initial beliefs to 259 retained sentences. The 259 were exported to a separate process and selected there with zero further derivation. The stress case using 257 fresh beliefs was refused before native execution. Once the pinned limit function runs, each queue length is strictly below its capacity. A zero-step initial return has its own size check. Native evidence exposes selected tasks, retained statements, ordered stamps and returned channels. It does not expose complete fired-rule parentage. The record catalog maps each common receipt digest to its raw program and stdout in the local pack. Individual readouts carry a reference to this receipt.
