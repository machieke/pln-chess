# Replacing evidence and replaying history

The host registry binds every current workspace name to an epoch and snapshot. Invalidation makes the old generation unavailable immediately, including cached queries and in-flight reads. Raw replacement inputs are constructed afresh. Publication validates ordered input identities and swaps the complete set of replacements under one lock. An interrupted or partial transaction leaves the affected generation unavailable. An explicit snapshot reference can still serve historical replay. For a source-wide correction, invalidate_observation(capture) obtains replacement tickets for all consumers of that capture. For a model-wide replacement, invalidate_model(model) does the same for all consuming workspaces. Publish requires the complete ticket set. The single-name rebuild interface creates or replaces an individually scoped workspace.
