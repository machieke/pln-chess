# Cycle 18 registered study

Registered before the new reference calculations and native replay. Starting
commit: `24f30ce8d4e0631f8937404929485dfdc0032f93`; delivery branch:
`cycle18-shared-parameter-contract`. Native calculus, stamps, accepted Cycle 12
checkpoint and operational source are protected. No native extension is authorized.

The population is exactly the 432 Cycle 17 preparation rows, with 48 admitted
conditional labels from 24 natural EE roots and 384 synthetic exclusions. The
six primary/overlap arms reuse this population. Source membership is read from
each original checkpoint and reconciled against its ledger and revision receipts.
The 96 held-out endpoints are historical context, not new reference training.

Source inspection establishes a critical distinction: the preparation function
computes one `reference(state, attacker, target)` result per occupancy and copies
its `label` into both rule rows. These are two annotations of one evaluation
result, not two independently measured rule successes. The environment is a
recorded PGN-derived state, not a new sensor measurement. No collection timestamp,
sensor error rate, or separately measured clearance outcome will be invented.

Event identity is a versioned namespace plus original root/occupancy/role locator,
independent of payload hashing. One environment record parents each evaluation
vector event, which parents both conditional annotations. Synthetic variants
parent to the natural environment. Only natural admitted vector components enter
the reference experiment. An event ID is immutable; changed content is rejected
unless a new explicit supersession event is registered. Application and prediction
records are never eligible observations. Different IDs do not imply independence.

Primary candidate meaning: theta_clear and theta_attack are positive-output
propensities of the two recorded label channels in a hypothetical repeated,
antecedent-qualified pipeline population. They are not rule truth probabilities,
measurement accuracy, or native confidence. Actual code copies one deterministic
oracle result, so the faithful identity restriction is equal parameters and equal
within-episode outcomes. Selection guarantees the observed positives for this
deterministic target. Stochastic extrapolation remains a supplied reference
hypothesis, not empirically identified reliability. We will also report the
deterministic interpretation (recorded eligible labels equal one) separately.

At most three finite model families are registered:

| Family | Prior and within-source likelihood | Query |
| --- | --- | --- |
| M-F | Uniform product grid; explicitly independent Bernoulli label channels | Success on two distinct future channel trials, conditionally independent given the shared parameter pair: E[theta_clear theta_attack] |
| M-J copy (primary identity-respecting hypothesis) | Uniform diagonal grid; one Bernoulli factor for the shared underlying label, never squared because two annotations exist | Two distinct future episode trials: E[theta squared]; repeating the same event instead gives E[theta] |
| M-J upper/lower (sensitivity hypotheses) | Uniform product grid; joint Bernoulli table with P(11)=min(a,b) or max(0,a+b-1) | Same two-distinct-trial query as M-F |
| M-B | Fixed posterior parameter marginals from a named fitted model; otherwise unrestricted coupling | Sharp min/max E[a b], with feasible extremal couplings |

All updates explicitly assume conditional factorization across source games.
Shared engines, openings and publisher make this unverified. M-F and the unequal
channel M-J sensitivity models are hypothetical measurement models, not faithful
descriptions of the observed copy operation. Upper/lower tables have identical
conditional Bernoulli marginals at every parameter state; the observed all-11
vectors cannot choose between them. Prior and posterior assumptions are reported
separately. M-B does not solve conditioning with an unspecified prior coupling.
Without supplied marginals, the real reliability/dependence query is
`not_identified`; no native TV-to-prior conversion is allowed.

The primary grid is {1/4, 1/2, 3/4}; registered sensitivity grids are {1/4, 3/4}
and {1/10, 3/10, 1/2, 7/10, 9/10}. Maximum 25 joint states. Exact rational
enumeration is exact for these supplied grids only. No continuous-grid claim.
One separate synthetic joint-noise control uses common bit-flip noise 1/10,
contrasted with independent bit flips and noiseless copies. No nuisance variable
is retained beyond the enumerated two-point noise table. Corruptions never enter
real native training or source ledgers.

Controls cover duplicate delivery, equal payload/distinct events, conflict and
supersession, two dependent annotations, vector likelihood multiplicity, repeated
applications (1/10/100), a genuinely new synthetic external event, source removal,
diamonds, cycles, self-training rejection, changed state/history, incremental vs
batch recomputation, shuffled order, impossible evidence, missing dependence and
resource exhaustion. Cycle 17 exact examples remain regression tests unchanged.

Outputs use `reference-semantics-v18` with point/bounded/not-identified/
inconsistent/resource-incomplete statuses, exact events/groups, complete priors,
likelihoods, query, posterior or feasible-set identity, and separate uncertainty
fields. No native stv, supported-positive classification or checkpoint output.

Limits: 25 states, 100 source groups, 2,500 likelihood evaluations per fit,
16,384-bit rational numerators/denominators, 1,000 application records/session;
research native replay <= 300 processes and 1 CPU hour; compact research outputs
<= 64 MiB; historical preservation <= 24 measured CPU hours and 8 GiB outputs.
Report overruns as incomplete, never as negative scientific findings. Full
preservation runs once after executable source/tests are frozen, with the actual
206-shard/584,112-row acceptance and 287 removal/27 history/2 recovery/76 holdout
controls. Targeted development checks are not that gate.

Success is assessed separately: engineering requires executable contracts, tests,

Publish source, tests, eleven reports and decisive small evidence in ordinary Git.
Audit every new reachable blob (10 MiB/blob; target 100 MiB/range), secrets, remote

## Recorded engineering amendment before final source freeze

The initial implementation freeze was `9dc9159de311a2b5304e4051eef2919e7994c19f`.
Review found that the reference generation hash needed to bind admitted component
masks and payload hashes, even when reciprocal selections produced the same
posterior. These bindings and a regression test are added before the final
freeze. The registered models, grids, query, source population and numerical
results are unchanged. Immutable tuple collections are also enforced at the
observation constructor boundary.

The initial preservation run is explicitly interrupted and retained, without
reusing its successful jobs at the corrected source. Final acceptance restarts
the complete gate once at the corrected freeze. Repeating the frozen native and
clean-reproduction commands requires 88 additional native processes after 134
retained development/initial executions. The research replay ceiling is therefore
amended from 200 to 300 **before** those reruns; the original ceiling was not
exceeded at amendment. The final canonical reproduction is counted separately
and remains within that amended ceiling as well. CPU, finite-state, arithmetic,
Git and output limits are unchanged. Interrupted preservation work and resource
counter limitations must be reported separately rather than silently discarded.
