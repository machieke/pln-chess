# Native composition decision gate

Production remains pinned to PLN `4405956947c4b53c7ff01bd565aa3b114bc970a1`, library SHA-256 `cdfb3f18bd7b336440fc7b4409209afddf0e64c41f17dee7eefc8f02718de433`, and PeTTa `ee5cacb6a6ecdd554a1c773aaf47e9a0f8a5af0f`. No vendored file was patched. Exact expressions, input TVs, outputs and source line numbers are in `artifacts/cycle4/native-probes/audit.json` and its executable `.metta` sibling.

The laboratory re-executes earlier probes and adds three-stage MP, missing/negative intermediate premises, probability-consistent and inconsistent deduction, zero-confidence marginals, repeated revision, conflicting revision, typed variable binding, inheritance predicate transfer and explicit stamp gates.

The selected production strategy is unary conditional composition with separately trained, disjoint evidence pools. A native MP chain can propagate an observation through Attack, exposure and NotLegal. The inference is conditional on each learned edge. It does not construct `And(A,B,C)` from independent movement/path/safety beliefs.

The pinned `|-` returns no derivation for independent `A`, `B` supplied as conjunction introduction, and no derivation for elimination from `And(A,B)`. An explicitly supplied joint sensor can be an MP antecedent, but that does not prove the conjunction. Nested implication application works operationally; it is not assumed to be conjunction.

The tested inheritance-to-predicate transfer wrapper also returns no derivation. Its source-level rule must not be confused with an operationally verified capability. This negative result is asserted by the audit and no production inheritance abstraction is shipped.

`Truth_Deduction` works for the measured, probability-consistent probe and returns zero confidence for an inconsistent probe. However, setting all marginal confidences to zero leaves the consistent output unchanged. That operational behavior is preserved in the audit and is a reason not to use deduction as a production substitute for unknown-condition composition. Native inversion has its upstream confidence penalty; it is not treated as unrestricted Bayesian inversion. Similarity and equivalence remain laboratory operators.

`Truth_Revision` increases confidence when the same premise is repeated. It has no stamp argument. `StampDisjoint` rejects overlapping evidence in the explicit native guard. The production scheduler enforces equivalent source-group separation before building each chain and never revises alternative inferred paths together.

Existing alternate branch audits are retained unchanged under Cycle 2. [OpenCog's fuzzy conjunction](https://github.com/opencog/pln/blob/a2e1354aa37f67952218b42e15686f8dc1629418/opencog/pln/rules/propositional/fuzzy-conjunction-introduction.scm) uses Scheme/Atomese operations and a minimum-based fuzzy TV. [Direct conjunction](https://github.com/opencog/pln/blob/a2e1354aa37f67952218b42e15686f8dc1629418/opencog/pln/rules/extensional/conjunction-direct-introduction.scm) measures member intersections in an AtomSpace population. Neither is a drop-in operator in this pinned PeTTa runtime. Source hashes, the upstream license notice, and snapshots are retained under `native-probes/upstream`; these are research references, not imported production code.

No optional port is shipped. Copying a fuzzy minimum or empirical-intersection formula into a new MeTTa function would require its own semantic and runtime validation; it would not establish that the pinned library already supports probabilistic independent-premise conjunction. General conjunction is a demonstrated limitation of this configuration, not a claim that all OpenCog implementations lack it.
