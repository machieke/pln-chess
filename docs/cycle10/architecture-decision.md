# ADR 10: preserve existing native inference and isolate strategic proposals

**Decision: retain the Cycle 9 no-go on a production native composition extension.** Cycle 10 enables no new native operator, upstream PLN modification, custom host-language probability rule or production chess-oracle gate. The accepted C8 checkpoint remains the default. Experimental adaptation checkpoints are separately named and are not operational promotions.

External game provenance adds a new evaluation population. Temporal transport adds event sequence, source identity and trust distinctions. Neither supplies the joint probability constraints or proof certificates missing from the [Cycle 9 composition review](../cycle9/composition-review.md). Historical eligibility is an evidence-availability question before it is a calculus question: incomplete event history cannot be repaired by asserting a conjunction.

The relevant architectural choices remain:

| Choice | Cycle 10 disposition | Reason |
|---|---|---|
| Existing native revision and conditional inference | Retain | Operational evidence can be revised and traced without changing truth-value formulas. Scope and positive-proof limitations stay explicit. |
| New joint composition operator in production | No-go | External accuracy or temporal replay alone does not establish a sound new calculus, dependence policy or universal safety proof. |
| Isolated bounded composition research | Proposal only | A separately authorized prototype would need a fixed atom bound, rational constraints, null-event semantics, overlap/retraction rules, certificates and an independent review. It is not enabled here. |
| New relative features within existing inference | Permitted only as controlled experiments | New evidence must retain provenance and structural holdouts. Host feature construction must not be called native conjunction. Final-test performance cannot justify weakening gates. |
| Strategic fields and move selection | Architecture preparation only | See the [strategic-readiness plan](strategic-readiness.md). No score, search or strategic selector is implemented. |

No exhausted conjunction probe is rerun merely to produce another negative result. New measurements can establish distribution drift, evidence needs or performance limits; they cannot convert mathematical reference calculations into native proof nodes.

Implementation acceptance is separate from model promotion. Any Cycle 10 source-bound receipt must prove all historical operational behavior and negative controls remain reproducible, preserve native/cache parity and source/runtime identities, and pass clean bootstrap and tests. New external errors are published as observations. They are not silently removed, reassigned to different datasets or concealed by a changed default threshold.
