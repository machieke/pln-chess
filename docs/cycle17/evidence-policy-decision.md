# Evidence policy decision

The minimal native evidence supports decision **A**: disjoint learned chains
work within the bounded two-cell experiment while shared chains remain blocked.
The isolated reference cases also support **C**: shared uncertainty is not
identified by the currently retained information. Neither finding establishes
a sound replacement evidence policy, generic recursion or statistical independence.
The native guard and truth-value calculus remain unchanged.

Both D-AB and D-BA return clearance and attack. Both shared arms return clearance
without attack. One shared training source is sufficient to reject the tested
matching pair. Each primary targeted parameter has the same native truth value,
strength 1 and confidence .923076923076923. The comparison changes actual admitted
training sets, without overwriting parameters or editing ancestry stamps.
The minimal matched pairs have no extra environmental or auxiliary-rule overlap.
Removing `clear-two` from the disjoint model still leaves the supplied recursive
route unable to complete two cells. Disjoint training across different rules
does not solve repeated use of one rule.

The diagnostic schema in [provenance.py](../../research/cycle17/provenance.py)
records schema identity, parameter generation, actual training-observation IDs,
training ancestry, environmental observation IDs, observed selection IDs and
parent derivations. A selection ID is a trace identity, never independent
evidence. The runtime does not expose complete fired-rule parents; those fields
remain null instead of being reconstructed as alleged observations. A native
`rule_` stamp maps to a stable declaration; `train_` maps to the actual registered
source-game ancestry; `obs_` maps to an observed fact occurrence. Parameter
generations are diagnostic content identities, not replacement source ancestry.

Three architecture choices have different obligations:

| Choice | What it can do | What it cannot establish |
| --- | --- | --- |
| Retain strict disjointness | Preserve current audited behavior and bounded chains with separate support | General composition of models trained on shared data, or independence from distinct IDs |
| Separate provenance roles | Distinguish reusable schema, learned parameter, training event, environmental event and trace occurrence | Correct correlated uncertainty propagation by typing alone |
| Represent joint uncertainty or bounds | State an explicit dependence model and compute its consequences in a future authorized design | A universal answer from the existing marginal TVs and flat stamps |

Strict disjointness has a measurable data cost: twelve admissions per parameter
require 24 unique registered games across a disjoint pair, compared with twelve
for a shared pair. Larger networks could require increasingly awkward source
partitions. Shared openings, engines and publisher remain even after partitioning.
This bounded route is therefore useful evidence, not a general learning architecture.

A future proposal should specify the following interfaces before implementing
any changed inference behavior:

1. **Observation registry.** A canonical event ID, source-group ancestry,
   observation model, contradiction policy and immutable payload hash. Duplicate
   delivery is idempotent. Two observations from one board must retain their
   common source even when their occurrence IDs differ.
2. **Parameter generation.** A schema ID, exact admitted event set, learner and
   model assumptions, retained uncertainty representation and generation lineage.
   Re-estimation creates a new generation without erasing prior observations.
3. **Application.** A binding and parameter-generation reference, current
   environmental inputs, observed trace identity and auditable parents where
   available. Applications do not add likelihoods or mint independent evidence.
4. **Dependence contract.** Specify whether repeated uses share a latent parameter,
   repeat one event or invoke conditionally independent trials. Require a joint
   representation, an explicit justified factorization, or identified bounds.
   Unknown dependence must remain unknown, not silently default to independence.
5. **Revision.** Define combination of observation likelihoods separately from
   parameter application. Shared observations are counted once; contradictory
   observations require a declared noise model or unresolved conflict.
6. **Graph behavior.** Common-ancestor diamonds retain shared latent/event identity.
   Circular derivations with no new external evidence cannot increase evidential
   weight. Termination and bounded resource behavior require separate analysis.

Acceptance obligations would include the real eleven-stamp witness, reciprocal
matched models, one-source overlap, all reference counterexamples, observation
replay, posterior reuse, environmental sharing, cycles, false hypotheses and
unequal uncertainty. A probability interpretation and a confidence interpretation
must be supplied independently; native support is not automatically calibrated
probability. Exact joint inference can grow exponentially, so any approximation
must state retained dependence, error guarantees or bounds and practical costs.

Migration would require a new explicitly versioned experimental policy and
checkpoint schema, trace-format compatibility, preserved old-policy replay, and
full legal/proof parity assessment. Keep the accepted operational model pinned
unless a separate authorization changes that decision. Audit retention must cover
original events, admission decisions, parameter generations, assumptions, exact
programs, runtime identities and observed outputs.

The recommended next experiment is an isolated finite joint-model specification
for two learned parameters with known shared observations, comparing exact bounds
and explicit factorization assumptions before any native implementation proposal.
“Ignore rule stamps” is not a complete solution: it fails to specify parameter
reuse, environmental dependence, revision or cycle behavior. No new guard,
probabilistic engine, path-length expansion or automatic move selection is activated.
