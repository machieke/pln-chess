# Architecture decision

Choose **Outcome A: finite composition works; generic reuse remains blocked**.

Native applicability, supplied two-cell composition, and native parameter
learning are demonstrated within their separate scopes. The fourth claim,
generic reusable-rule reasoning with honest provenance, is not established.
The successful finite representation adds a complete bounded domain hypothesis;
it neither discovers structure nor generalizes to arbitrary path lengths.

Keep the experiment opt-in and the operational legal model unchanged. The
finite result is useful as a bounded capability, but extending a large family of
finite rules now would leave the shared learned-ancestry failure unexplained.
The recursive failure and real learned-chain failure are reproducible with the
unchanged runtime, and their premises structurally match in separately labeled
native diagnostics. Removing provenance would hide the research problem.

Prioritize a separately authorized, precisely specified evidence-semantics study
of **shared model uncertainty versus repeated environmental evidence**. Start
with this exact learned two-rule chain, its eleven overlapping training-game
stamps, and the existing diamond/replay/cycle controls. Define the mathematical
meaning of reusing uncertain parameters before proposing any guard change. No
runtime change is authorized by this delivery.

A separately registered three-cell supplied conditional is a possible later
bounded-capability experiment. It should follow the evidence-policy decision,
retain the current counterexamples, and never be described as solving recursion.
Do not resume broad preference learning or add automatic move selection as a
substitute for resolving this boundary.

The evidence limits remain material: all admitted conditional outcomes are
positive; source episodes share engines/openings; test geometry overlaps training;
native traces expose selected tasks and returned beliefs, not a complete
fired-rule tree; probabilities are not calibrated. These do not erase the
bounded native execution result, and they prevent stronger claims.
