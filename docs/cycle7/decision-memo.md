Current native PLN supports learned conditional evidence and provenance-backed negative chains. A high truth-value strength remains a conditional belief, not a calibrated probability or a complete proof of chess legality. Operational predictions remain useful; strict and experimental modes abstain when positive composition is unproved.

A successful nested implication needs a supplied relation to the target; product introduction is absent; typed inheritance is source-present but the tested signatures return empty in this runtime. These do not establish the independently learned held-out knight-capture witness. The exact outputs, evidence IDs and premise-removal controls accompany the feasibility report.

Continue only bounded empirical learning work. This avoids promising that more data alone will create an operator missing from the pinned rule set.
