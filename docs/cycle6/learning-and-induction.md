# Learning and induction

Production C6 performs no retraining: C4 positive and C5 negative beliefs are preserved exactly. The factorial checkpoint is isolated and contains no C4 local observation hypotheses, only independent bridge conditionals and separately supervised primitives. Dependence groups, evidence IDs and held-out combination exclusions are explicit.

C2–C5 native probes are reexecuted in the inherited audit. C5 induction is rerun using its original population, first observation per original group and ancestry exclusions. Its 7 proposed consequent conditionals are host-selected geometry descriptors; they are not native concept invention. Population counts, estimated marginals and exact native calls are retained.

The new run executes enabled, disabled, redundant sham, halved-marginal, zero-marginal-confidence and overlapping-evidence controls. It applies the induced rules to 20 held-out C6 base combinations. Changed local TVs are not counted as predictive benefit. **Global classification gains: 0.** No defensible global rule injection was identified, so operational induction remains disabled.

Shared populations and sample construction limit these marginals. Zero marginal confidence does not itself suppress every native formula. The overlap control executes the native stamp guard and refuses extra revision. All assumptions, failed/empty outputs and evidence provenance are in `artifacts/cycle6/induction.json`.
