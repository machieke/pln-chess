# Typed premise planner

Schema 5 (`typed-premise-planner-v5`) embeds the exact C4 reference model and a separately replayed typed-premise ledger. [Ontology](../../src/pln_chess/cycle5/ontology.py) separates raw observations, host projections, learned conditionals and move-specific native conclusions. Stable hypothesis IDs hash the version, family, target and relative descriptor. FENs, squares, piece IDs and games appear only in input, binding and provenance.

The hierarchy includes geometry, destination, per-cell ray occupancy, boundary, exposure and temporal observations. Pre-move frames are sensed once per inference call; successor/transit frames retain the C4 structural edit semantics. A raw occupied-cell relation is not a legality verdict. The learned `RayObstruction` conditional and an independently trained obstruction-to-illegality bridge supply a native negative witness. Destination pooling retains royal contact but drops unnecessary victim identity. No exact-context refinement is generated from heldout errors: conflicts remain visible and the hierarchy records that policy.

The [planner](../../src/pln_chess/cycle5/inference.py) first executes the unchanged C4 reasoning core, then shares applicable typed-premise native calculations. It preserves C4 positive projections as diagnostics but requires a complete global theorem before emitting supported legal. Since no verified independent-premise conjunction or universal safety aggregation is available, default C5 emits supported illegal or unknown; incomplete work remains incomplete. This deliberate loss of positive coverage is measured, not presented as a precision improvement.

New negatives use `Truth_ModusPonens` and `Truth_Negation` over disjoint learned antecedent and bridge groups. Alternative negative witnesses are preserved and the first sufficient witness is selected deterministically; their TVs are never fused. Native evidence choice remains inside same-proposition conditional evaluation. A local positive category is not a competing global safety theorem.

Cache scopes include model, runtime manifest, ledger, position, temporal receipt, thresholds and suppressed families. The C4 and typed stages use separate bounded caches. The export supplies content-addressed DAG references, while inherited C4 proof occurrences remain uninterned. Combined node/time/estimated-metadata budgets produce incomplete output when exhausted. A native failure never falls back to a host calculation.

The seeded candidate grammar already distinguishes piece motion families. These inductive biases are disclosed and are not evidence that PLN discovered chess geometry. Positive combination failure is an actual limitation of this implementation, not a claim that all possible native programs are incapable of composition.
