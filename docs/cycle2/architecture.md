# Cycle 2 architecture

Cycle 2 is an opt-in, schema-2 native-partial learner. Schema-1 APIs, checkpoint hashes and inference remain supported. `Model.load` dispatches by schema; unknown schemas and corrupt hashes fail. Select a checkpoint through the existing CLI or inspector, or request `representation='hierarchical'` in `infer_moves`. Use `options={'representation':'hierarchical-relative-v2'}` in the public training API. There is no automatic migration: retraining from labeled records constructs a new model with distinct IDs and provenance.

`cycle2/descriptors.py` makes host-derived projections of the existing sensor facts. Tier 0 identifies a piece; tier 1 adds a relative movement family; tiers 2 and 3 add intermediate-content classes or destination occupancy; tier 4 contains the bounded local movement context; tier 5 adds distance and first nonempty step; tier 6 retains the original exact context for diagnostic fallback. Learned IDs hash the target, tier and descriptor. No board ID, absolute coordinate, FEN or evidence ID enters a local key. File-reflection symmetry and distance abstraction for sliders are declared grammar biases, not learned theorems. Pawn owner-relative displacement and edge distances retain relevant directional/boundary information.

Intermediate occupancy is decomposed into sensed cells, first nonempty cell, empty prefix/suffix lengths and content classes. The distance-agnostic relation stores the set of nonempty content classes. An empty set is an observation of the cells, not a precomputed assertion that movement is unblocked. Prefix/suffix observations are exposed for inspection; this cycle learns on content classes and first-nonempty refinements, not arbitrary segment programs.

Movement keys exclude all opponent-to-king frames. Each successor opponent has a separately indexed relative attack descriptor, using piece type, motion family and intermediate content classes. Sliding attacks can require remote occupancy: that nonlocal sensing belongs to the attack channel. Castling transit frames remain present in the exact diagnostic context; they have no general compositional transit-safety theorem.

Every hypothesis is an alternative conditional. The most specific available reusable legal context is primary (tier 5 before tier 4); exact context is fallback only. General movement motifs are not silently converted into legality. Native confidence choice selects between positive/negative conditional channels, direct/induced origins and learned exposure counterevidence. Overlapping evidence is never revised across hypotheses. Decisive conflicts, including exact-context counterexamples, cause display abstention while retaining the raw native TV and all competing paths. This is an uncertainty policy, not a new PLN truth-value formula.

`cycle2/native.py` memoizes exact pure native expression DAGs. Logical proof nodes, rule IDs and evidence remain distinct; identical scalar native computations may share an execution result. Keys incorporate the runtime identity and prerequisite expression identities. No Python strength/confidence calculation is used. The optional in-memory session is scoped by its caller; there is no persistent PeTTa process.

Production modules import neither the oracle nor training/evaluation packages. The native/sensor boundary is visible on proof nodes and relations, and checked statically and with oracle imports disabled at runtime.
