## Targets and measurements

Clear means both intervening cells are empty in the bound reference state. Attack means rook sliding influence to a distinct occupied endpoint at distance three, including a friendly occupied endpoint. NoAttack is the native encoding's explicit contrary channel. Influence does not mean move legality or king safety. Clearance is measured by an explicit coordinate/path occupancy audit; influence independently by python-chess Board.attacks. Both share the source state and implementation environment, so they are not independent observations. State/role failures and incomplete reference states yield unresolved measurements. Each conditional uses its own target measurement. Clear training requires the observed two-empty-cell antecedent; rook-attack training requires rook kind and separately measured Clear. An antecedent-qualified positive curriculum is not an unbiased sample of arbitrary positions.

All 128 natural roots are measured and evaluated. The first 12 test roots, in manifest order, receive all nine E/O/U two-cell variants. E and O intervene on the underlying reference state; U withholds the original cell occupancy from inference while retaining it for evaluation. These 108 dependent variants have separate intervention/withholding populations, never 108 independent games. The same 12 roots receive entity renaming, 180-degree rotation, and left-right reflection as dependent representation controls.

## Models and inference

Seven arms: H = frozen Cycle 17 S-AA; F = supplied finite rules; D-AB = Clear from A, terminal from B; D-BA reciprocal; S-AA and S-BB shared groups; P = both learned rules at prior (strength .5, confidence 0). Four new fits use all qualified records in manifest order. The other supplied templates remain unchanged. Native revision only, with supplied observation confidence .5. Environmental facts retain supplied confidence .99, other supplied rules .95. These are assumptions, not measured reliability. Actual ancestry is retained on both learned rules.

Each episode/arm has independent Clear and Attack invocations over identical raw observations and the complete frozen rule set. No Clear answer bridges the invocations. Frozen budgets: steps 64, tasks 128, beliefs 256, timeout 15 seconds per query. Support thresholds: strength >= .6 and confidence >= .1. A bounded empty result is unknown; timeout, process or parse failure is incomplete; supported incompatible channels are conflict. No threshold or budget tuning on test results.

Controls: duplicate delivery, reversed delivery, all-clearance-support removal, actual leave-one-A refit, rule removal, required-empty-premise removal, wrong state, wrong role. All refits retain genuine source ancestry. E/O/U variants use F, D-AB, S-AA; representation controls use D-AB. Controls never alter natural training labels.
