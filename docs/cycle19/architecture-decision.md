# Architecture decision

Cycle 19 separates current-position measurement, native support and active-evidence management. The operational chess model, native calculus, evidence-disjointness guard and supplied rule structures remain unchanged. The appropriate conclusions are A, B, C and D together, within the registered finite scope.

**A — Domain measurement established.** Clear is an explicit two-cell occupancy audit. Attack is a separately implemented sliding-influence check on the fully specified reference board. Both have event/component lineage, invalid-binding handling and hand-declared fixtures. Their agreement does not make the two measurements statistically independent: they share a state, representation and implementation environment.

**B — Native learning and bounded transfer demonstrated.** Measured antecedent-qualified annotations revise the two supplied conditional parameters through the pinned native operator. The four new fitted arms each use 24 source games per target; equality of their learned parameters is an observed consequence of the positive qualified curriculum, not a host override. Connected Clear → Attack queries use raw relative observations and complete templates. Transfer is limited to new games, endpoint roles/locations, surrounding contexts, and the registered direction holdout. All paths still have exactly two intervening cells; no rule-structure discovery or arbitrary recursive generalization is claimed.

**C — Probability interpretation unresolved.** The event is Attack(attacker,target,state) given available observations, templates and admitted learning evidence. The study does not identify a distribution for observation errors, representation errors, conditional applicability, schema reliability or bounded computation. Its `not_identified` output does not reuse Cycle 18's two-future-trial probability. Native confidence is neither calibrated correctness probability nor a Beta posterior, effective independent-game count, or posterior precision. An all-positive qualified curriculum does not identify a stochastic failure rate.

**D — Native extension remains necessary for shared-evidence and recursive composition.** The unchanged guard blocks combining premises whose evidence stamps overlap, including shared training-source ancestry and repeated recursive rule stamps. Disjoint chains compose under the measured conditions. Host supersession/refitting can change which measurements are current, but cannot repair that native capability boundary. It is not legitimate to mint new rule stamps, remove shared ancestry or import an audited Clear to bypass it.

The smallest future capability to investigate is a native composition rule that can account soundly for explicitly shared evidence and reusable rule applications without treating them as new independent observations. Its truth-value semantics, dependency representation, consistency behavior and proof accounting remain unresolved. This is a proposal for a separate authorized cycle, not an implemented extension.

The active-evidence journal has a narrower purpose: immutable history, explicit descendant invalidation, stale-use rejection, actual refitting, atomic active-view publication, and reproducible historical snapshots. Cache lookup is host reuse of an existing proof. Neither the journal nor the cache changes native truth arithmetic or establishes calibrated uncertainty. No experimental checkpoint is promoted to the accepted legal/default model.

On the held-out test set, D-AB covered 56/56 Attack queries, and all 30 supported positive predictions agreed with the influence measurement. The registered Wilson intervals are 93.6–100% for coverage and 88.6–100% for precision and recall under an exchangeable-game approximation. The TCEC opening and engine dependence limits extrapolation from these intervals. For H, S-AA, S-BB and P, positive precision is undefined because each arm made zero positive Attack predictions. Their explicit obstruction coverage was 26/56.
