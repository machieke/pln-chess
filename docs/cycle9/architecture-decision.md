# ADR 9: retain existing operators; permit only a future isolated research proposal

**Decision recommendation: use option A operationally. A bounded option B prototype is justified as research only after explicit authorization. Production option B is no-go. Option C can improve learned conditional coverage but does not presently solve multi-premise composition.** No new operator is authorized or activated by this memo.

| Alternative | Feasibility and uncertainty | Effort estimate | Mathematical risk and compatibility | Required tests and migration | Recommendation |
|---|---|---|---|---|---|
| A — existing native operators | Demonstrated native revision, conditional elimination, negation and negative chains; positive global legality remains partial. | Days for targeted abstractions; ongoing evaluation. Estimate, not measured work. | Lowest calculus risk. Existing checkpoint formats and proof traces remain available. | All established regressions, new independent cohorts, causal removals, cached/reference equality. No checkpoint migration required. | Continue as the operational architecture. |
| B — isolated native extension | Finite-world credal core is formally feasible; statistical certificates, native solver and conditional-learning contract remain open. | Roughly 4–8 engineer-weeks for a bounded prototype plus independent mathematical review; production timeline cannot yet be estimated. | New truth-value type; no automatic `(stv s c)` conversion. Dependence, solver soundness, contradiction and evidence overlap are primary risks. | Exact rational toy cases, proof certificates, malformed IDs, scope mismatch, overlap/cycle attacks, retraction, timeout, permutation and cache tests; independent review. Parallel API/checkpoint namespace, no silent migration. | Conditional go for future isolated research; no-go for production integration. |
| C — representation within existing rules | A learned joint-feature antecedent can reuse an existing conditional. Typed unary transfer may help when a relation is actually supplied. Neither introduces missing joint probabilities from marginals. | 1–3 weeks for a new, explicitly stated representation hypothesis and controls; uncertain research payoff. | Risks returning to complete-position memorization or presenting host feature construction as native conjunction. Keep piece-relative grammar and proof attribution. | Held-out structural families, transformed-source exclusion, evidence removal, exact native witnesses and counterexamples where one premise changes. Preserve older models. | Pursue only a materially new hypothesis; do not repeat failed nested implications. |

The extension is justified by a reusable capability gap, not by a requirement to achieve a particular chess score. It would be useful only if it preserves constraints and provenance through several deductions and retractions. A narrow interval without that retained model is inadequate, as the [composition review](composition-review.md) demonstrates.

Before an option B prototype is authorized, its plan should fix the atom bound, supported rational constraints, null-event conditional semantics, solver certificate format, evidence-overlap rules, sampling/certificate assumptions, and explicit incomplete result behavior. A prototype must stay independent of chess and return the richer type. Enabling it in the operational learner would require a separate decision with reviewed empirical calibration, conditional-learning and scope-transport evidence.

This decision does not claim that finite operational successes prove universal chess correctness. It also does not claim that calibrated diagnostic probabilities establish a native theorem of legality.
