# Compact auditable inference

Cycle 14 adds an opt-in content-addressed proof store and three views: `summary`, paginated `proof_graph`, and reconstructable `full_archive`. Existing Cycle 13 APIs remain available. The [schema contract](compact-proof-contract.md), [implementation](../../src/pln_chess/cycle14/proofs.py), and [storage tests](../../tests/test_cycle14_proofs.py) define the exact boundary.

The store interns every JSON container into a typed Merkle DAG. Object IDs bind canonical content under the versioned `pln-proof-object-v14` domain. References are typed internal values, so a caller's ordinary dictionary containing a reference-looking string cannot become an unintended link. Dictionary order is canonical; list order and repeated occurrences remain intact. Derivations with equal truth values remain distinct whenever their native expression, premises, evidence or provenance differ.

The compact inference path builds, interns and releases each full endpoint before retaining only the projections needed for comparisons. It does not assemble the final deeply duplicated legacy response to discard it. A response root references endpoint and proof objects. SQLite transactions batch inserts and use durable commit semantics. A persistent store retains requests across process restart. The host index is **not** a persistent native PLN reasoning graph; persistent native-resident atoms remain zero.

Request identity binds full observed state including unknown squares, supplied history, ordered candidates, actor through state, branches and horizons, all model versions, runtime manifest, production source hash, provenance and inference options. Changing evidence changes the model identity. Changing scope, model, history, branch or budget cannot satisfy a previous request identity. Delivery metadata reports a cache hit separately from the original native execution receipt. Reusing an already checked proof is not a faster native calculus.

Standalone archives include the full reachable object set, a manifest hash and the exact expanded canonical JSON hash. Import verifies object digests, dependencies, cycles, reachability and reconstruction before committing. Missing or corrupted objects fail explicitly. Literal values such as `1.0`, `-0.0`, booleans and Unicode survive byte-exact canonical expansion; browser uploads preserve raw JSON text rather than parsing and reserializing numeric lexemes through JavaScript.

`canonical_chunks` streams expanded JSON when explicitly requested. Serialization compiles shared subtrees, with bounded memoization of small expansions, without losing repeated occurrence counts or the maximum expansion budget. The decoded object cache has 2,048 entries; the bounded serialization memo is at most 64 MiB with subtrees no larger than 8,192 bytes. Durable content is verified on each distinct object read in an expansion. Summary retrieval verifies its request/root binding; a full archive or graph traversal verifies all reached dependencies.

Archive reconstruction preserves **all** stored metadata exactly. Matched independent Cycle 13/14 comparisons omit only `execution` and `incremental` telemetry; native expressions, TV values, ordered premises, evidence multiplicity, provenance and graph identities remain in parity checks. Immediate and temporal integration tests run both implementations independently. The [complete clean proof replay](../../artifacts/cycle14/clean-research/proof-replay/verified.json) is the corpus-level receipt; its scope is recorded expression replay, complemented by fresh observation construction on selected source/split/missingness strata.

The real-browser round trip exported a standalone archive, uploaded that exact file, and reconstructed **14,468,187 bytes** with SHA-256 `e7484744c9d73fdb625b1ce93874dac948ba51d6ff2d2e64495de4b6cdea4dec`. A durable handle survived a server restart and graph pagination retrieved objects 17–32 of 7,933. [Downloaded files and integrity receipt](../../artifacts/cycle14/ui/browser-downloads/http-framed/integrity.json) retain this controlled native example. HTTP reconstruction validates into a bounded-memory spooled file before sending an exact `Content-Length`, so a failed import cannot masquerade as a completed download.

The first feature generation was interrupted after 109 completed cases for a profile-guided host serialization improvement. Those receipts and archives remain under `immediate-g1`; the selected complete generation is `immediate-g2`, with `temporal-g1` for continuations. The [selection receipt](../../artifacts/cycle14/features/selected-generations.json) states that no operator, descriptor or model outcome caused the change. Overlapping cases are compared for exact scientific parity. Instrumented optimization profiles are diagnostics under contention; headline latency, memory and payload claims come only from [matched isolated benchmarks](performance.md).
