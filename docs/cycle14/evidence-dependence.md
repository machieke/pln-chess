# Evidence generations and dependence

The Cycle 14 ledger separates immutable observations from the active label generation. [Evidence storage](../../src/pln_chess/cycle14/evidence.py) uses validated hash-chained events, a separate process lock, atomic replacement and durable sync. Reingesting identical evidence is idempotent. An observation can retain several superseded versions while exactly one is active. Conflicting immutable content is rejected before mutation. Activation and rollback are recorded events, not deletion of the previous evidence.

The observation identity binds its packet, label, original source/game ancestry, temporal context, runtime, dataset, reference evidence and generation. The scientific model hash additionally binds its descriptor grammar, native channel values, evidence IDs, training report and ledger digest. Model-generation input contracts are frozen before ingesting new ledger rows; an incompatible rerun cannot silently append evidence to an already fitted generation.

Connected ancestry includes roots, games, pair reversals, multiple horizons, transformations, counterfactual descendants, repeated searches and supplied continuations. Native `Truth_Revision` processes one representative of each consistent dependent component per conditional key. Internally contradictory dependent components are withheld and enumerated. A component may inform distinct horizon-specific keys, but its descendants do not become independent evidence for the same key. Unknown references and unavailable observations do not provide false directional updates.

The [executed dependence receipt](../../artifacts/cycle14/dependence/summary.json) joins these controls: repeated historical labels, repeated temporal reference analyses, repeated continuation observations, an explicitly unsafe independence ablation, conflicting dependent labels, byte-identical checkpoint and ledger replay, old/new generation activation, and rollback to the old checkpoint. The unsafe arm is an evaluation artifact and cannot become the default. Changes in total files, analyses or native calls are not changes in the number of independent groups.

[Matched ablations](ablations.md) separately compare new independent groups with repeated old evidence. Repeated handled evidence must preserve channel truth values even when checkpoint provenance/version changes because its full delivery ledger differs. Byte identity is required only for an exact replay with identical observations and variant identity. Counterfactual reversal fits remove the complete supporting ancestry across all training horizons, then rerun native training; deleting only a displayed explanation is not an evidence-removal experiment.

The controlled unit test reproduces the expected confidence inflation when dependent copies are deliberately counted independently and the absence of inflation with ancestry handling. The [native test](../../tests/test_cycle14_native_learning.py) also rejects held-out supervision and verifies that a conflicting rerun does not modify the prior ledger. Those disclosed synthetic checks are engineering tests; empirical inflation counts and model effects belong to the registered-corpus receipt.
