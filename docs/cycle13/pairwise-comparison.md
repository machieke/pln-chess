# Pairwise comparison contract

Status: design registration; implementation and measurements remain pending the baseline gate.

The experimental API accepts a supplied position and two explicit structural candidates. It returns an independent legality belief for each, separately inferred before/after fields, bounded concept candidates, diagnostic relational changes, the supplied categorical comparison packet, native preference channels, provenance, proof graphs and gaps. It never chooses a move to play.

The four result states are `A-preferred`, `B-preferred`, `indeterminate`, and `incomplete`. A directional answer requires a learned conditional, a native application and the registered strength/confidence thresholds. Unsupported conditions, insufficient evidence, indistinguishable relative descriptors, conflicting supported directions and no-demonstrated preference remain indeterminate. Failed or budget-exhausted computation is incomplete. Legal uncertainty remains visible independently of these states.

Fields use an explicit query domain shared by the two candidates. Attack observations concern occupied opponent targets; defense observations concern occupied friendly wards; exposure observations concern the actor's king; ordinary mobility concerns the supplied candidate mover identities. The API must disclose its bounded domain and all unobserved or incomplete relationships. Missing relations cannot count as contradicted relations. Separate changes in supported relations are host observations, not a strategic scalar score or a native conjunction.

The primary abstraction compares the candidates' categorical changes in attack, defense, ordinary mobility and king exposure. Candidate roles are canonicalized using relative observations. A reversed query shares its rules and training evidence and swaps its directional channels. Absolute squares, move strings, full-position identities and source-game identities cannot distinguish learned rules. A relative descriptor that cannot distinguish the candidates cannot justify a directional preference.

The A, B and no-demonstrated-preference channels have independent raw PLN truth values. Their strengths are not normalized probabilities. Native revision learns each conditional from external observations; native modus ponens applies it to a host-assembled packet with disclosed observation confidence. There is no host replacement of a PLN formula. Independently supported field and concept records do not establish a joint strategic theorem.

Full recomputation and cached inference must retain identical semantic records and proof graphs. Cache identity binds the field/concept/preference models, native runtime, options and actual observation dependencies. Changed occupancy, unknown cells and hypothetical successors cannot reuse stale observations. Returned structures must not allow callers to mutate cached provenance.

The API validates the entire supplied envelope before native work, rejects reference labels or engine scores as inference inputs, bounds pair batches and response branches, and discloses whether a budget applies to a stage or to the entire request. It does not infer transitivity or exhaustively enumerate opponent replies.
